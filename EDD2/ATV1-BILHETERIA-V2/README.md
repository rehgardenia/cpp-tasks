# 🎭 Sistema de Bilheteria

Aplicação desktop desenvolvida em **C# e Windows Forms** para gerenciamento de reservas e faturamento de uma bilheteria.

O projeto possui **600 poltronas**, organizadas em **15 fileiras × 40 lugares**, com criação dinâmica dos componentes da interface.

## ✨ Funcionalidades

* 🪑 Mapa interativo com 600 poltronas;
* 🎟️ Reserva de ingressos Inteira ou Meia;
* ⚠️ Controle de poltronas ocupadas;
* 💰 Cálculo do faturamento;
* 📊 Exibição da quantidade de lugares ocupados;
* 🖥️ Interface criada dinamicamente em código.

## 💵 Valores

| Fileiras |  Inteira |     Meia |
| -------- | -------: | -------: |
| 1–5      | R$ 50,00 | R$ 25,00 |
| 6–10     | R$ 30,00 | R$ 15,00 |
| 11–15    | R$ 15,00 |  R$ 7,50 |
